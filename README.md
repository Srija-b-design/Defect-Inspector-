Industrial Defect Inspector is a computer vision system that automatically identifies defects in manufactured products. It fine-tunes a pretrained CNN (EfficientNet-B0, compared with DenseNet121) on the NEU Surface Defect dataset to classify six defect types: crazing, inclusion, patches, pitted surface, rolled-in scale, and scratches. Each prediction comes with a confidence score, and Grad-CAM heatmaps show which regions of the image influenced the decision. The app supports batch inspection and generates quality-control reports summarizing the defects found.
